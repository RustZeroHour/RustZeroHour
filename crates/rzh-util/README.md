# rzh-util

Shared utilities for the [RustZeroHour](https://github.com/RustZeroHour/RustZeroHour)
engine: the Zero Hour game CRC, the deterministic pseudo random number
generators and the name-key interning subsystem, ported bit-exactly from
the C++ baseline.

- **Origin** (baseline `571a7c5`, Zero Hour configuration, non-retail
  branches): `Core/GameEngine/Include/Common/crc.h`,
  `Core/GameEngine/Source/Common/crc.cpp`,
  `Core/GameEngine/Source/Common/RandomValue.cpp`,
  `GeneralsMD/Code/GameEngine/Include/Common/NameKeyGenerator.h`,
  `GeneralsMD/Code/GameEngine/Source/Common/NameKeyGenerator.cpp`.
- **Parity**: level **P0** (byte-exact), enforced by the committed golden
  vectors in `tests/golden/`, generated by `tools/differential/`.
- **Determinism**: `#![forbid(unsafe_code)]`, no global mutable state
  (the `TheNameKeyGenerator` singleton became an owned
  `NameKeyGenerator` value), fixed-width integers only, `f32` with the
  original operation order.

See `docs/RUST_MIGRATION_PLAN.md` for the porting rules this crate follows.

## Usage

```rust
use rzh_util::{Crc, GameRng, NameKeyGenerator};

let mut crc = Crc::new();
crc.update(b"123456789");
assert_eq!(crc.get(), 0x0000_63C5);

let mut logic_rng = GameRng::seeded(42);
let damage_roll = logic_rng.random_int(0, 100);

// Name keys: same name -> same key; the interning order must be
// identical on every lockstep client.
let mut names = NameKeyGenerator::new();
let tank = names.name_to_lowercase_key("AmericaTank");
assert_eq!(names.name_to_lowercase_key("AMERICATANK"), tank);
assert_eq!(names.key_to_name(tank), Some(&b"americatank"[..]));
```

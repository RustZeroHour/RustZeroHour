# rzh-compress

EA compression codecs for the RustZeroHour data pipeline (migration plan
§3.4, Phase 1).

## Contents

- **`refpack`** — the RefPack LZ codec transcribed from
  `Core/Libraries/Source/Compression/EAC/{refdecode,refencode}.cpp`.
  Compressed streams are **byte-identical** to the C++ implementation in
  both directions (parity level P0): the golden vectors in
  `tests/golden/refpack.txt` are generated by compiling the original
  sources, and round-trip property tests cover structured, compressible
  and incompressible inputs.

## Not ported (yet)

- The Huffman and B-tree EAC codecs — not reachable from Zero Hour data.
- The Nox LZH codec.
- The `CompressionManager` factory — arrives with its consumers in
  `rzh-vfs`.

## Determinism notes

This is data-path code, not simulation code, but it still follows the
plan's discipline: no `unsafe`, no global state, and malformed input
returns `Result::Err` where the C has undefined behaviour (valid streams
decode identically — the error paths are strictly extra safety).

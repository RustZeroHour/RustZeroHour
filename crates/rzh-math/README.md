# rzh-math

Deterministic simulation math for the
[RustZeroHour](https://github.com/RustZeroHour/RustZeroHour) engine: the
WWMath scalar helpers and the float/integer vectors, ported bit-exactly
from the C++ baseline.

- **Origin** (baseline `571a7c5`, Zero Hour configuration, deterministic
  branches, i.e. `USE_DETERMINISTIC_MATH = 1`):
  `Core/Libraries/Source/WWVegas/WWMath/wwmath.h`,
  `vector2.h`, `vector2i.h`, `vector3.h`, `Vector3i.h`, `vector4.h`.
- **Parity**: level **P0** (bit-exact), enforced by the committed golden
  vectors in `tests/golden/`, generated by `tools/differential/`.
- **Determinism**: `#![forbid(unsafe_code)]`, `f32` with the original
  operation order, original quirks preserved and documented (see
  `Vector4`'s `SubAssign` and `lerp_out`, `Vector3::quick_length`,
  `Vector2::normalize_free` / `quick_distance`).
- **`Matrix3` / `Quaternion`**: the 3x3 matrix and quaternion
  (`matrix3.{h,cpp}`, `quat.{h,cpp}`) with the axis-angle/quaternion
  conversions, inverse, slerp (exact / fast / cached) — golden-pinned
  against a C++ transcription linked to the pin.
- **`fast`**: the `WWMath::Init()` fast-trig lookup tables and the
  `Fast_*` entry points (lazily built, bit-identical to a C++ `Init()`).
- **`gmath`**: the GameMath (FreeBSD msun) float functions the game pins
  for its transcendental entry points (`Sin`…`Atan2`, `Pow`, `Exp`, `Log`,
  hyperbolics, `Float_To_Long`), transcribed line-for-line from the pin and
  verified against 78K golden vectors generated by compiling the pinned C
  sources — see [ADR-001](../../docs/adr/001-sim-numerics.md). Still
  deferred: the `Fast_*` lookup tables (land with the quaternion port) and
  the double-precision entry points (tools only).

See `docs/RUST_MIGRATION_PLAN.md` for the porting rules this crate follows.

## Usage

```rust
use rzh_math::{Vector2, Vector3, scalar};

let mut v = Vector3::new(0.0, 3.0, 4.0);
v.normalize();
assert_eq!(v, Vector3::new(0.0, 0.6, 0.8));

// WWMath semantics, not Rust's: round == floor(x + 0.5).
assert_eq!(scalar::round(-0.5), 0.0);

// Division multiplies by the reciprocal, like the original operators.
let d = Vector2::new(1.0, 2.0) / 0.1;
```

# rzh-math

Deterministic simulation math for the
[RustZeroHour](https://github.com/RustZeroHour/RustZeroHour) engine: the
WWMath scalar helpers, vectors, matrices, quaternions and geometry types,
ported bit-exactly from the C++ baseline.

- **Origin** (baseline `571a7c5`, Zero Hour configuration, deterministic
  branches, i.e. `USE_DETERMINISTIC_MATH = 1`):
  `Core/Libraries/Source/WWVegas/WWMath/wwmath.h`,
  `vector2.h`, `vector2i.h`, `vector3.h`, `Vector3i.h`, `vector4.h`.
- **Properties**: `tests/properties.rs` — the algebraic invariants
  (unit normalization, orthogonal-inverse rotations, box growth,
  frustum bounds) over arbitrary quarter-step inputs.
- **Parity**: level **P0** (bit-exact), enforced by the committed golden
  vectors in `tests/golden/`, generated by `tools/differential/`.
- **Determinism**: `#![forbid(unsafe_code)]`, `f32` with the original
  operation order, original quirks preserved and documented (see
  `Vector4`'s `SubAssign` and `lerp_out`, `Vector3::quick_length`,
  `Vector2::normalize_free` / `quick_distance`).
- **`Matrix3` / `Quaternion`**: the 3x3 matrix and quaternion
  (`matrix3.{h,cpp}`, `quat.{h,cpp}`) with the axis-angle/quaternion
  conversions, inverse, slerp (exact / fast / cached) — golden-pinned
  against a C++ transcription linked to the pin.
- **`Matrix3D`**: the 4x3 homogeneous transform (`matrix3d.{h,cpp}`,
  the `NO_ALLOW_TEMPORARIES` branch the Zero Hour build uses): the
  post/pre/in-place rotation families, translations, scales, the
  look-at family, both inverses (general cofactor/adjugate with
  determinant + orthogonal transpose), axis-aligned box transforms,
  `Re_Orthogonalize`, `Lerp` (position lerp + quaternion slerp) and
  `Solve_Linear_System` — whose fourth column carries the original's
  `Vector4::operator-=` **W-column quirk** (W added, not subtracted),
  preserved and golden-pinned verbatim.
- **`Matrix4`**: the full 4x4 matrix (`matrix4.{h,cpp}`): the ortho and
  frustum projections, transpose, the cofactor inverse with
  determinant, the mixed `Matrix3D` products and the point/vector
  transforms — with the original's `/=`-**multiplies** and `-=` W-column
  quirks preserved. The fov-based `Init_Perspective` is the one entry
  point not golden-pinned (its `tan` is platform libm in the original
  too).
- **`aabox` / `plane` / `aaplane` / `frustum` / `colmath`**: the
  WWMath geometry types (`aabox.{h,cpp}`, `plane.h`, `aaplane.h`,
  `frustum.{h,cpp}` and the `CollisionMath` overlap-test subset from
  `colmath.{h,cpp}`, `colmathaabox.h`, `colmathplane.cpp`): the
  center-extent and min-max axis-aligned boxes with their
  double-precision `Volume` and early-return quirks, the
  normal-plus-distance plane with its inverted-`D` convention (and the
  untouched-`t` parallel-segment quirk), the axis-aligned plane, the
  view frustum with the reflected-camera corner swap and the
  whole-vector clip-distance scaling, and the box/plane overlap
  verdicts with their two different epsilons
  (`WWMATH_EPSILON` vs `COINCIDENCE_EPSILON`).
- **`fast`**: the `WWMath::Init()` fast-trig lookup tables and the
  `Fast_*` entry points (lazily built, bit-identical to a C++ `Init()`).
- **`gmath`**: the GameMath (FreeBSD msun) float functions the game pins
  for its transcendental entry points (`Sin`…`Atan2`, `Pow`, `Exp`, `Log`,
  hyperbolics, `Float_To_Long`), transcribed line-for-line from the pin and
  verified against 78K golden vectors generated by compiling the pinned C
  sources — see [ADR-001](../../docs/adr/001-sim-numerics.md). Still
  deferred: the double-precision entry points (tools only).

See `docs/RUST_MIGRATION_PLAN.md` for the porting rules this crate follows.

## Usage

```rust
use rzh_math::{Vector2, Vector3, scalar};

let mut v = Vector3::new(0.0, 3.0, 4.0);
v.normalize();
assert_eq!(v, Vector3::new(0.0, 0.6, 0.8));

// WWMath semantics, not Rust's: round == floor(x + 0.5).
assert_eq!(scalar::round(-0.5), 0.0);

// Division multiplies by the reciprocal, like the original operators.
let d = Vector2::new(1.0, 2.0) / 0.1;
```
